名單轉檔工具

把每期的中獎發票名單轉成哈希值，再貼進 index.html。

這個檔案不要上傳到 GitHub。只在自己的電腦上用瀏覽器開啟。 轉檔全程在本機完成，明碼手機號碼不會離開這台電腦，也不會進入 commit 紀錄。

1 · 貼上名單

直接從 Excel 框選資料列複製貼上即可（不含標題列也可以）。
欄位順序：發票日期　發票號碼　中獎金額　領獎截止日　隨機碼　載具
載具欄不論是 18 碼完整載具、10 碼手機號碼、或被 Excel 吃掉開頭 0 的 9 碼，都會自動處理。隨機碼一律捨棄不寫入。

2 · 參數

SALT 每期換一組新的，換了之後舊名單就對不上。ITERATIONS 不要改動。兩項都必須與 index.html 完全一致。

3 · 輸出

整段複製，貼進 index.html 中 const WINNERS = { 與 }; 之間，取代原有內容。

換期流程

  1. 本機開啟本工具，貼上新一期名單，換一組 SALT，轉檔。
  2. 把輸出貼進 index.html 的 WINNERS 區塊。
  3. 同時修改 index.html 設定區的 PERIOD、DEADLINE、SALT 三項。
  4. 核對輸出的發票筆數與名單列數相同，再 push。
  5. 原始 xlsx 不要放進 repo 資料夾。
